# Classic Business Centre - Web Portal

A modern, responsive, and animated website designed for Classic Business Centre, Goa. The site features a light theme, a comprehensive catalog of services, location details, and a dedicated Print Order page integrated with WhatsApp.

## Features
* **Modern Light Theme:** Clean, high-contrast design inspired by modern software platforms.
* **Responsive Layout:** Perfectly adapts to mobile, tablet, and desktop screens using CSS Grid and Flexbox.
* **Scroll Animations:** Elements fade and slide into view as the user scrolls down.
* **WhatsApp Integration:** The print order form dynamically generates a WhatsApp message with the user's order details.
* **Vector Placeholders:** Uses scalable vector icons (FontAwesome) and dynamic image placeholders to represent services.

## File Structure
* `index.html` - The main catalog, business overview, services, and locations.
* `print.html` - The dedicated print order form.
* `style.css` - All styling, variables, animations, and responsive queries.
* `script.js` - Mobile navigation, scroll animations, and WhatsApp form handling logic.

## Usage
1. Keep all files in the same directory.
2. Open `index.html` in any modern web browser to view the site.
3. To test the WhatsApp integration, fill out the form on `print.html` and submit it.
